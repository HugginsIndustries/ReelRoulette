WebUI design mockup

The whole visible UI of v0.15.0, for approval before each milestone builds it. Every page works at desktop and phone widths and follows the system light or dark theme. Magenta dashed boxes are mockup notes; notes that start with “Proposed” or “Open” still need a decision.

dock_to_rightMain page

  • The player's one panel button opens the panel on its last tab, and closes it. Favorite and Blacklist stay on the player; the seek row ends with the volume control.
  • Drag the handle between the player and the panel, or focus it and use the arrow keys. Open or closed, side, width, and last tab survive a reload.
  • Below 800 px wide, or on a touch screen under 500 px tall, the panel is a full-screen overlay. The chip at the player's top left shows what Auto-Pause did.
  • Library: the filter summary line, placeholder tiles while a page loads, and selection (the checklist button, Ctrl or Shift+click, or a long press) with bulk actions.
  • Filter, Tags, and their dialogs as approved so far, plus the browser-playable option. Play an .avi or .wmv file to see the format notice.
  • Stats: the current file, with Show in File Manager or Copy Path, and the library. Click the file name in the header to open it.
  • Settings: autoplay mode, Advance after, seek and volume steps, loudness normalization, panel side, Auto-Pause, the shortcut reference, and diagnostics.
  • Keyboard shortcuts work: K, J, L, arrows, R, F, B, A, M, comma and period, 1 to 5, T, S, P, and Shift+F.
  • The Mockup tab on the left edge sets the situation: pairing asked for, the server machine, and a read-only volume.

admin_panel_settingsAdmin view

  • The full-page view the header's admin icon opens: server and updates, web access, control, refresh, library transfer, backups, sources, duplicates, the testing suite, clients, logs, and events.
  • Duplicate review opens within it. The control token gate shows first from another machine.

errorField validation pattern

  • Each state of the durations (parsed strictly), the new preset name, and the Edit Tag and Edit Category names, with what a screen reader gets.
  • Apply when the field that is not valid is out of view.

desktop_windowsDesktop retirement notice

  • What the last desktop build shows once on its first start.
