Docs: Plan log categories, a minimum log level, and multi-value log viewer filters

- The structured log schema gets a required `cat` category (`action`, `access`, `job`, `lifecycle`, `connection`, or `general`, which the writer sets when an entry has none) and a configurable minimum level for `last.log`, `info` by default; the WebUI log methods take an optional category, and server code can set one through `ILogger`.
- The Admin Log Viewer replaces the free-text level box with one checkbox per level, adds multi-select category and source filters, and its `lvl`, `cat`, and `svc` filters take several values.
- Library Query Performance keeps one library query line per request and adds its elapsed time, so a reload writes one line once it is a single request; in the v0.14.0 manual pass a six-page reload from two WebUI clients wrote twelve lines.
